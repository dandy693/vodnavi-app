# BRAND DESIGN GUIDE — VODNAVI 統合世界観・デザイン仕様書

VODNAVI が運営する 3 つのサイト（Moterist / VODNavi / Concierge App）における **世界観、視覚デザイン、コンテンツ要件、Google アルゴリズム（E-E-A-T / Information Gain）対応のマネタイズ仕様** を規定する。
本ガイドラインは「絶対の法律」として、執筆・画像生成・コピーライティングのすべてを統制する。

---

## 1. コア・コンセプトと世界観

### ■ コンセプト：『ビブリア・エロティカ（官能の図書館）』

チープなアダルトサイトに見られるネオンピンクや過度な原色は徹底的に排除する。目指すべきは、**「高級ホテルのラウンジ」「洗練された夜の書斎」「歴史あるプライベートライブラリ」** である。

- **読者体験（UX）**：ユーザーがサイトに足を踏み入れた瞬間、知的好奇心と内なる本能が同時に満たされるような、圧倒的な「特別感」と「安全性」を提供する。
- **文体・口調（執筆標準）**：「徹底解説！」「おすすめ〇選！」といった安易なアフィリエイト臭を封印する。
  - 良い例：「今夜、あなたの孤独と欲望に寄り添う、至高のエンターテインメントを紐解きます」
  - 知的でミステリアスな、洗練されたバーテンダーのようなトーン（紳士・淑女の語り口）を維持する。

### ■ ASP 時間軸ロードマップ（収益動線の時間軸戦略）

収益最大化と世界観の整合性を両立させるため、ASP の露出は **時間軸で段階的に解放** する。フェーズを跨いで露出ルールを破ることは、CVR の希釈と世界観の毀損を同時に招くため厳禁とする。

- **【フェーズ 1：基盤構築期（目標月商 30 万円）】 — FANZA 100% 一点集中**
  - Moterist の全記事、Concierge App の全プロンプト、すべての CTA は **FANZA 単一の成約ゴール** に絞る。
  - 比較選択肢を意図的に削ぎ落とすことで、ユーザーの迷い（決定疲労）を排除し CVR を極大化する。
  - 他社 ASP・他ジャンルへの言及・誘導は一切しない。「VODNAVI＝FANZA コンシェルジュ」というブランド認知を最短で確立する。
- **【フェーズ 2：拡大加速期（目標月商 100 万円）】 — 裏メニューとしての限定解放**
  - 月商 30 万円突破後、Concierge App の **裏メニュー**（ポップアップ／特定インテント条件下）でのみ以下 2 ASP を限定解放する：
    - **DMM TV**：同一 DMM アカウントを活かした **最高効率のクロスセル**（既ログインユーザーへの自然な追加成約）。
    - **U-NEXT**：無料登録報酬による **離脱ユーザーのセーフティネット**（FANZA で買わなかったユーザーを取りこぼさない）。
  - **Moterist 側の集客記事には他社 ASP を一切露出させない**。集客面の単純さは維持し、AI 接客面でのみ複雑性を許容する。

## 2. 視覚デザイン仕様（カラー・タイポグラフィ）

3 つの異なるドメイン（moterist.com / vodnavi.jp / app.vodnavi.jp）を跨ぐため、デザインの一貫性がなければユーザーは離脱する。以下のビジュアルアイデンティティを強制する。

### ■ カラーパレット

- **ベースカラー（70%）**：`#121212`（リッチブラック）
  - *意図*：映画館の暗闇、夜の書斎、大人のプレミアム感を演出。すべての背景に適用。
- **メインテキスト（20%）**：`#E0E0E0`（プラチナホワイト）
  - *意図*：純白（`#FFFFFF`）は暗い背景においてコントラストが強すぎ、目が疲れるため、可読性を最大化する淡いグレーを採用。
- **アクセント・CTA カラー（10%）**：`#D4AF37`（シャンパンゴールド）
  - *意図*：購買心理学において「特別感・最高級・信頼」を象徴する色。**この色が付いた場所は「クリックできる場所（アクションの核心）」としてユーザーの脳に条件付けする。**

### ■ タイポグラフィ

- **集客・信頼サイト**：知性と情緒を演出するため、見出しやキーメッセージには「明朝体風（Serif 系）」のラグジュアリーなフォントを採用。
- **成約アプリ（チャット UI）**：システムとしての信頼性と直感性を担保するため、視認性の高い「モダンゴシック（Sans-serif 系）」を採用。

## 3. 3 サイト別の具体的な構成・デザイン・中身

### ① 集客拠点：`moterist.com`（WordPress × THE THOR）

直接「FANZA おすすめ」を狙う競合と真っ向勝負せず、ユーザーの「孤独」「退屈」「知的欲求」という **感情の手前** をジャックして独占する。

- **デザイン・レイアウト**：
  - 雑多なブログ形式（新着順にカードが並ぶだけ）を完全廃止。ビジュアル重視の「オンラインマガジン型」へ。
  - ファーストビュー（ヘッダーバナー）は、`#121212` の背景に、ゴールドの文字で **「今夜、あなたの本能と知性を満たす 1 本を。」** というメッセージと、洗練されたアイキャッチのみを配置。
- **5 大ピラー記事の役割と具体的タイトル案**：
  1. `fanza20250329`（Beginner Guide）
     - *タイトル*：「恥をかかないための、大人のための配信エンターテインメント嗜み方」
     - *中身*：教養としての VOD 利用、大人が満足する高画質・独占作品の価値を説く。
  2. `fanza20250331`（Registration / Benefits Guide）
     - *タイトル*：「10 分後にはじめる、秘匿性の高い至高のプライベート空間へのパスポート」
     - *中身*：会員登録のステップを最高級ホテルのチェックインのようにエレガントに解説。
  3. `fanza_otoku250114`（Safety / Anxiety Resolution）
     - *タイトル*：「クレジットカード明細、視聴履歴の安全性。紳士のプライバシーを守る 3 つの鉄則」
     - *中身*：E-E-A-T を意識し、徹底したセキュリティ、匿名性、家族にバレない運用の技術解説。
- **送客 CTA（Call to Action）のデザイン**：
  - 記事末尾の CTA は、四角く太いゴールド（`#D4AF37`）のボタン。ホバーするとリッチブラック（`#121212`）に反転。
  - コピーは **「AI コンシェルジュに今夜の気分を伝えて、あなた専用の裏メニューを出力する（無料）」** に統一。

### ② 信頼の盾：`vodnavi.jp`（Next.js）

E-E-A-T（専門性・権威性・信頼性）を担保し、検索上位および事業の法的安全性を維持するための「公式の顔（身元引受人）」である。

- **デザイン方針**：
  - Apple 公式サイトのような、広大な余白（リッチブラック）に洗練されたプラチナホワイトの文字が浮かぶ「ミニマルテクノロジーデザイン」。
- **必須コンテンツ（E-E-A-T ハック）**：
  - **トップページ**：次世代映像検索 AI「VODNAVI」の解析精度の高さ、プライバシー完全保護の仕組みをインフォグラフィックで解説。
  - **ポリシーページ**：「運営者情報（法人格、運営委員会）」「コンテンツ制作・査読ポリシー（AI と人間の専門家によるダブルチェック体制）」「利用規約」「プライバシーポリシー」。
- **送客動線**：
  - ヘッダーの右上に、常に美しく明滅するゴールドのボタン **「AI コンシェルジュを起動（無料）」** を固定配置。

### ③ 成約の核心：`app.vodnavi.jp`（Next.js × AI チャット）

ユーザーの熱量が最高潮に達する、ファネルの最下流（成約エンジン）。

- **デザイン・レイアウト**：
  - 完全なダークモード。LINE のようなチープな吹き出し UI は厳禁。薄いグレー（`#1E1E1E`）のモダンなカード UI がタイムラインに流れる高級感。
- **流入インテントに応じたプロンプト動的最適化（URL 設計の拡張）**：
  Moterist（集客）から App へ遷移する際、従来の `source=moterist` に加え、読者の意図を識別する `intent` パラメータを付与する。
  - `?source=moterist&intent=beginner`：挨拶文をビギナー向けに優しく、利用方法の案内を強化。
  - `?source=moterist&intent=actress`：特定の女優やニッチジャンルを深掘りするプロンプトへ自動スイッチ。
  - `?source=moterist&intent=discount`：セールやお得情報、コスパ重視の提案ロジックを展開。
- **商品カード（FANZA アフィリンク）の仕様**：
  - 生成した「この作品があなたの〇〇な感情を満たす理由（100 文字）」の推薦文を添える。
  - 購入・詳細ボタン（CTA）は、最も購買意欲を刺激する **「FANZA 公式で作品の詳細・サンプル映像を確認する（18 禁）」** に統一。
- **【年齢確認の盾（リーガル防衛）】**：18 禁コンテンツの提案を行う性質上、`app.vodnavi.jp` へのアクセス直後、ユーザーに対して **18 歳以上であることを確認するモーダルウィンドウ（年齢確認ゲート）の表示を義務付ける**。判定結果はクッキー（例：`vodnavi_age_verified=1` / 期限 1 年）に保持し、これが未通過の状態では **コンシェルジュ機能および API 呼び出しを完全に遮断** する構造とする。
  - 初回訪問時、画面全体を覆うモーダル（背景透過なし）で「18 歳以上ですか？」を尋ね、「はい」のみ通過させる。「いいえ」は外部の年齢制限案内ページにリダイレクト。
  - クッキー判定はサーバー側でも実施し、未通過のリクエストは API ルートで 403 を返す。
  - 年齢確認モーダルは『ビブリア・エロティカ』の世界観に従い、ダーク × ゴールド配色で組む。煽情的な画像を含めない。

## 4. 執筆・画像生成における不変条件

### ■ 執筆ルール

- 「ピンク・ネオン・安易な露出」を封印し、「ゴールド・ダーク・知的なエロティシズム」へ翻訳して書く。
- 直接的なワードを避け、「シネマティックなライティング」「みずみずしい質感」等のサニタイズ表現を徹底する（規約 BAN 回避）。
- 「徹底解説」「おすすめ〇選」「絶対」「圧倒的」「必見」のような陳腐な煽情詞は使わない。
- 1 段落で 1 メッセージ。比喩はワイン／本／ジャズなど成熟した文化記号から引く。

### ■ アフィリエイトリンクの取扱い

- 記事内 CTA URL に `af_id=` の値を **直書きしない**（ハードコード禁止）。
- アフィリエイト ID 等は環境変数や WordPress 共通定数を経由して動的に挿入される前提で書く。
- 末尾 CTA URL は `?source=moterist` + 必要に応じて `&intent=beginner|actress|discount` を付ける形式。

### ■ 年齢確認・コンプライアンス

- 18 歳未満を想起させる表現を避ける（学生・学園テーマは「成人俳優のコスプレ作品」の前提を明示）。
- 偽セール／架空のレビュー数／不当な期限煽りは全面禁止（景表法 / 規約違反）。
- 効能の断定（「治る」「効く」）は使わない。

## 5. 行動経済学レイヤー（ナッジ設計）

| 効果 | 適用箇所 | 実装方針 |
|---|---|---|
| **アンカリング** | 比較表の左端列 | 最高単価を左端に置き、隣の本命を相対的に「お得」に見せる |
| **社会的証明** | レコメンドカード | 「過去 7 日で N 回提案」を控えめに 1 行で表示（事実根拠のあるもののみ） |
| **希少性** | セール特集の CTA | セール期限を分解して秒数まで表示せず、**日単位** で「残り N 日」と書く |
| **損失回避** | 末尾 CTA | 「今夜の 1 本を逃すと、また探し直しに 30 分」と暗示的に置く |
| **デフォルト効果** | 初期挨拶 | 流入元 × 意図ごとに最も成約に近い 1 案を最初に提示 |

禁則：偽セール／架空のレビュー数／不当な期限煽りは全面禁止（景表法 / 規約違反）。

## 6. PR / 記事公開前チェックリスト

提出前に以下を全てクリアする：

- [ ] パレット遵守：`#FFFFFF` / `#000000` / 非合意色を導入していない
- [ ] CTA URL：`source` パラメータ（+ 必要に応じて `intent`）が付いている
- [ ] フォント：見出し＝セリフ、本文＝サンセリフ
- [ ] 余白：4 / 8 / 16 / 32 / 64 px の整数倍
- [ ] トーン：NG 形容詞（すごい・圧倒的・必見・絶対）を使っていない
- [ ] E-E-A-T：執筆者の Experience が 1 段落以上含まれる
- [ ] Information Gain：既出情報の焼き直しのみで構成されていない
- [ ] 18+：固定ページとフッタにコンプライアンス表記が残っている
