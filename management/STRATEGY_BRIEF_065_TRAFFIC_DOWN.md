## 1. 物理データ（GSC、実測）
- 4週間合計: クリック **3,750** / 表示 **10.6万** / CTR **3.5%** / **平均掲載順位 8.8**。
- 日次波形（チャート実読）: 〜05/18 低調 → **05/19-22 急スパイク（ピーク ~375クリック/日）** → 05/23-25 急落（~120/日）
  → 05/28-30 小さな二次の山 → 06/01-09 緩やかに漸減（~150→~100/日）。
- 作品別 signal（サマリー推奨）: `works/videoa/gkok00002` **-85%** / `works/videoa/lulu00423` **+155%**。

## 2. 結論：真因 = 初期スパイクの正常化（構造的減少ではない）
- 「減少」の実体は **05/20-22 の一時的な検索バーストが沈静化**したこと + 6月の緩やかなドリフト。特定作品
  （gkok00002 等）の検索需要が一過性に跳ね、その後フェードしたもの。
- **構造/技術/ペナルティ要因は棄却**できる根拠: **平均掲載順位が 8.8 で安定**（順位崩落なし）。アルゴリズム
  ペナルティや大規模デランクなら順位が悪化するが、していない。手動対策も無し（設定監査 2026-06-10、robots 有効）。
- むしろ本日(06-11)までに **sitemap 解析エラーを修正(PR #36)** し works/genres 約1,800 URL が取込可能になった＝
  土台はマイナスでなくプラス方向。
- **データ期間が4週間しかない**ため「減少トレンド」と呼ぶには母数不足。初期スパイクの基準化局面と見るのが妥当。

## 3. GA4 / Ahrefs / GTM の関与度（横断はしていない・正直）
- **GA4**: 本ブリーフでは未取得。ただし GSC の organic クリック波形が新規ユーザー（organic）の代理指標であり、
  スパイク正常化の説明に GA4 のチャネル分解は新情報を足さない見込み。必要なら p489519780 で First-user source を確認可。
- **Ahrefs**: 被リンク/DR は日次スパイクの原因になり得ない（数日で急変しない）＝本件の駆動要因ではない。
  かつ Ahrefs AWT Free は 4xx/詳細が UI 非表示で精度限界（[[reference_ahrefs_vodnavi_awt_free]]）。
- **GTM**: 計測タグ生存は 06-08 監査で確認済（剥離なし）。配信ラグは検索クリック数の減少とは無関係。
