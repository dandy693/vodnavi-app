# STRATEGY BRIEF 057: 本番環境における成約ファネルのサイレントデス（無音窒息）即時検知プロトコル

- **ステータス**: APPROVED (CSO 策定 / 収益防衛)
- **策定日**: 2026-06-09
- **対象ドメイン**: app.vodnavi.jp (本番成約アプリ環境)
- **関連**: `STRATEGY_BRIEF_053`〜`056`（環境変数・検証ゲート・インテント継承）/ ALERTS 自動エスカレーション・ボード

## 1. 目的と背景

`BRIEF_053`〜`056` により、プレビュー環境での検証およびインテント（クエリパラメータ）の完全継承仕様は確定した。本ブリーフは、本番デプロイ後に万が一「FANZA API トークン失効」「`proxy.ts` でのクエリ揮発」等の致命的障害が発生した際、アフィリエイト報酬の発生がゼロのまま放置される「サイレントデス」をシステム的に自動検知し、人間の手動巡回（手作業）を排除することを目的とする。

## 2. 必須監視要件（遵守ルール）

1. **API 例外のテレメトリ化ゲート**:
   - `app-concierge/src/proxy.ts` および API ルートにおいて、FANZA API からのレスポンスエラー（401 Unauthorized, 403 Forbidden、またはパースエラーによる空配列返却）が発生した場合、ユーザー画面にエラーを素通しせず、背後でエラーログを構造化（JSON）出力せよ。
2. **無音窒息検知（サイレントガード）**:
   - フロントエンドのカード描画コンポーネントにおいて、API 認証未設定警告（`image_6dd163.png` 相当の例外）が本番環境（`NODE_ENV === 'production'`）でトリガーされた場合は、即座に重要度 `high` の例外としてログ監視システム（Vercel Logs 等）にシグナルを射出すること。

## 3. ガバナンス不変条件

- 本監視の実装に際しても、`BRIEF_054` のカーブアウト仕様（§2.4）を厳格に適用し、GA/GTM 計測タグによる Preview 環境の汚染防止機構（`null` ガード）を寸分でも破壊してはならない。
- ALERTS 起票時は本ファイルの自動エスカレーション規約に従い、`status: open` で起票し、物理 verify 完了後にのみ `resolved` へ flip する（事実と矛盾する resolved 宣言を禁止、[[feedback_verify_before_resolving_alerts]]）。

## 4. 境界（BRIEF_037 堅持）

moterist.com 完全凍結・5記事 SEO 永久保護・clean面/成人導線の境界は不変。本監視は本番 app.vodnavi.jp の成約 API 健全性のみを対象とする。
