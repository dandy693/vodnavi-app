# 📊 VODNAVI 運営KPIスプレッドシートデータモデル

Googleスプレッドシート、またはExcelでそのままテーブル定義して使用する、データ駆動型意思決定用スキーマである。

## 1. 「01_日次入力」シート（Raw Data Input）

### カラム定義とデータ型
| 列番号 | カラム名 (ヘッダー) | 型 / 数式表記 | 目的・説明 |
| :--- | :--- | :--- | :--- |
| **A** | 日付 | 日付 (YYYY-MM-DD) | 主キー |
| **B** | main_PV | 数値 | `vodnavi.jp` のGoogle Analytics 4 総PV数 |
| **C** | app_PV | 数値 | `app.vodnavi.jp` のGoogle Analytics 4 総PV数 |
| **D** | アフィリクリック数 | 数値 | カスタムイベント `product_click` 発火総数 |
| **E** | 新規登録_CV | 数値 | FANZAアフィリエイト管理画面確定：新規無料登録件数 |
| **F** | 動画購入_CV | 数値 | FANZAアフィリエイト管理画面確定：単発動画購入件数 |
| **G** | 発生報酬額 | 通貨 (¥) | その日の発生報酬総額 |
| **H** | 主要記事公開本数 | 数値 | その日に新規公開した `vodnavi.jp` の記事数 |
| **I** | リライト完了本数 | 数値 | その日にリライト完了した記事数 |
| **J** | API同期エラー件数 | 数値 | システムログ内のAPI同期失敗・欠損エラー検知数 |
| **K** | 記事_CTR | 数式 `=D/(B+C)` | サイト全体の送客・クリック効率（目標5〜15%） |
| **L** | クリック後_CVR | 数式 `=(E+F)/D` | クリックに対する成約の割合（目標1〜3%） |
| **M** | EPC | 数式 `=G/D` | 1クリックあたりの平均報酬（導線の質） |
| **N** | RPM | 数式 `=G/(B+C)*1000` | 1,000PVあたりの収益（メディアの総資産価値） |
| **O** | 最重要流入キーワード | テキスト | Search Console 上のその日の最高インプレッションKW |

## 2. 「02_週次・月次サマリー」シート（Pivot / Dashboard）

### 目標逆算と現状の乖離（北極星：月商100万円への防衛ライン）
- **月間総PV目標**: 227,500 PV (main + app 累計)
- **目標記事CTR**: 10.0%  → 必要クリック数: 22,750 クリック
- **目標クリック後CVR**: 2.0% → 必要成約数: 455 件
- **想定平均報酬単価**: 2,200円 (新規登録系を主軸に据えることで高水準維持)

### スプレッドシート用 異常検知アラート数式（条件付き書式推奨）
- **CTR警告**: `=K2<0.05` (5%未満の場合、セルを赤色に。CTAの文言・配置、または比較表の視認性に重大な欠陥があると判断)
- **CVR警告**: `=L2<0.01` (1%未満の場合、セルを赤色に。検索意図と作品訴求、あるいは高単価新規登録への誘導導線がミスマッチしていると判断)
- **エラー警告**: `=J2>0` (1件でもシステムエラー・API障害がある場合、開発チームへ即時エスカレーション)
