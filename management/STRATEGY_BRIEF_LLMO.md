# 1. 目的と背景
生成AI検索エンジン（Perplexity, SearchGPT, Gemini等）からのインテント流入を独占するため、Next.js 16への移行・統合を進める `app.vodnavi.jp`（成約の核心・AIチャットエンジン、フロントの集客・信頼メディアは `vodnavi.jp`）を、LLMが最高効率で引用・抽出できる「構造化データの要塞」へ進化させる。

# 2. ガバナンスと5つの盾の継承
- **世界観の死守**: 『ビブリア・エロティカ（官能の図書館）』における高級・知性・ダーク×ゴールドの意匠を完全維持。
- **リーガル防衛**: `src/proxy.ts`（※ Next.js 16構造に準拠。`src/middleware.ts` の新規作成は禁止）に実装済みの年齢確認ロジックおよび認証ゲートウェイを完全統合。
- **ドメイン識別**: 凍結された `moterist.com` からの流入はホスト名および `?source=moterist` にて厳格に個別計測。

# 3. 各ロールへの要求仕様
- **【CTO】**: 
  - 既設のJSON-LD（既存のProduct/Offer/Person/ItemList構造）を、未カバーの「女優ハブページ」「特定ジャンルURL」へ100%拡張・自動配置。
  - 既設の `robots.txt` に主要AIクローラー（GPTBot, PerplexityBot等）に対する個別インデックス・引用最適化ルールを明示的に追加。
- **【CCO】**: 
  - 生成AI検索の複合インテント（ペルソナがAIに問いかける特異な文脈）を逆引きした、コンシューマーに刺さるディープコンテンツ骨子の設計および量産。

# 4. メトリクスガード節
- AI検索経由のセッションおよびキーイベントの変動が週次で-15%を超えた場合、クローラーブロックおよび構造化データのパースエラーの自動検出（ALERTS.mdの定義に基づく）を即時実行する。
