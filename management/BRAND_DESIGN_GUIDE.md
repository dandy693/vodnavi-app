# BRAND DESIGN GUIDE — VODNAVI-GROUP 統合世界観・デザイン仕様書

> 本ドキュメントは、VODNAVI-GROUPが運営する3つのサイト（Moterist / VODNavi / Concierge App）における**世界観、視覚デザイン、コンテンツ要件、およびGoogleの検索アルゴリズム（E-E-A-T / Information Gain）をハックするための最高レベルのマネタイズ仕様**を規定する。
> 全AIエグゼクティブ・チーム（CSO / CTO / CCO）は、本ガイドラインを「絶対の法律」として遵守し、一切のブレなき統一された読者体験（UX）を構築せよ。

---

## 1. コア・コンセプトと世界観（世界観の定義）

### ■ コンセプト：『ビブリア・エロティカ（官能の図書館）』
チープなアダルトサイトに見られるネオンピンクや過度な原色は徹底的に排除する。目指すべきは、**「高級ホテルのラウンジ」「洗練された夜の書斎」「歴史あるプライベートライブラリ」**である。

- **読者体験（UX）**: ユーザーがサイトに足を踏み入れた瞬間、知的好奇心と内なる本能が同時に満たされるような、圧倒的な「特別感」と「安全性」を提供する。
- **文体・口調（CCOの執筆標準）**: 「徹底解説！」「おすすめ〇選！」といった安易なアフィリエイト臭を封印。「今夜, あなたの孤独と欲望に寄り添う、至高のエンターテインメントを紐解きます」といった、知的でミステリアスな、洗練されたバーテンダーのようなトーン（紳士・淑女の語り口）を維持せよ。

### ■ ASP時間軸ロードマップ（収益動線の時間軸戦略）
収益最大化と世界観の整合性を両立させるため、ASPの露出は **時間軸で段階的に解放** する。フェーズを跨いで露出ルールを破ることは、CVRの希釈と世界観の毀損を同時に招くため厳禁とする。

- **【フェーズ1：基盤構築期（目標月商30万円）】 — FANZA 100% 一点集中**
  - Moterist の全記事、Concierge App の全プロンプト、すべての CTA は **FANZA 単一の成約ゴール** に絞る。
  - 比較選択肢を意図的に削ぎ落とすことで、ユーザーの迷い（決定疲労）を排除し CVR を極大化する。
  - 他社ASP・他ジャンルへの言及・誘導は一切しない。「VODNAVI＝FANZAコンシェルジュ」というブランド認知を最短で確立する。
- **【フェーズ2：拡大加速期（目標月商100万円）】 — 裏メニューとしての限定解放**
  - 月商30万円突破後、Concierge App の **裏メニュー**（ポップアップ／特定インテント条件下）でのみ以下 2 ASP を限定解放する：
    - **DMM TV**：同一 DMM アカウントを活かした **最高効率のクロスセル**（既ログインユーザーへの自然な追加成約）。
    - **U-NEXT**：無料登録報酬による **離脱ユーザーのセーフティネット**（FANZA で買わなかったユーザーを取りこぼさない）。
  - **Moterist 側の集客記事には他社ASPを一切露出させない**。集客面の単純さは維持し、AI 接客面でのみ複雑性を許容する。
  - 解放のトリガー判定（intent条件・収益閾値・ユーザー属性）は STRATEGY_BRIEF で個別に定義する。

## 2. 視覚デザイン仕様（カラー・タイポグラフィ）

3つの異なるドメイン（moterist.com / vodnavi.jp / app.vodnavi.jp）を跨ぐため、デザインの一貫性がなければユーザーは離脱する。以下のビジュアルアイデンティティを強制する。

### ■ カラーパレット（Tailwind CSS v4 / THE THOR 共通）
- **ベースカラー（70%）**: `#121212`（リッチブラック）
  - *意図*: 映画館の暗闇、夜の書斎、大人のプレミアム感を演出。すべての背景に適用。
- **メインテキスト（20%）**: `#E0E0E0`（プラチナホワイト）
  - *意図*: 純白（`#FFFFFF`）は暗い背景においてコントラストが強すぎ、目が疲れるため、可読性を最大化する淡いグレーを採用。
- **アクセント・CTAカラー（10%）**: `#D4AF37`（シャンパンゴールド）
  - *意図*: Googleの購買心理学において「特別感・最高級・信頼」を象徴する色。**この色が付いた場所は「クリックできる場所（アクションの核心）」としてユーザーの脳に条件付けする。**

### ■ タイポグラフィ
- **集客・信頼サイト**: 知性と情緒を演出するため、見出しやキーメッセージには「明朝体風（Serif系）」のラグジュアリーなフォントを採用。
- **成約アプリ（チャットUI）**: システムとしての信頼性と直感性を担保するため、視認性の高い「モダンゴシック（Sans-serif系）」を採用。

## 3. 3サイト別の具体的な構成・デザイン・中身

### ① 集客拠点：`moterist.com`（WordPress × THE THOR）
直接「FANZA おすすめ」を狙う競合と真っ向勝負せず、ユーザーの「孤独」「退屈」「知的欲求」という**感情の手前**をジャックして独占する。

- **デザイン・レイアウト**:
  - 雑多なブログ形式（新着順にカードが並ぶだけ）を完全廃止。ビジュアル重視の「オンラインマガジン型」へ。
  - ファーストビュー（ヘッダーバナー）は、`#121212` の背景に、ゴールドの文字で**「今夜、あなたの本能と知性を満たす1本を。」**というメッセージと、洗練されたアイキャッチのみを配置。
- **5大ピラー記事の役割と具体的タイトル案**:
  1. `fanza20250329` (Beginner Guide)
     - *タイトル*: 「恥をかかないための、大人のための配信エンターテインメント嗜み方」
     - *中身*: 教養としてのVOD利用、大人が満足する高画質・独占作品の価値を説く。
  2. `fanza20250331` (Registration / Benefits Guide)
     - *タイトル*: 「10分後にはじめる、秘匿性の高い至高のプライベート空間へのパスポート」
     - *中身*: 会員登録のステップを最高級ホテルのチェックインのようにエレガントに解説。
  3. `fanza_otoku250114` (Safety / Anxiety Resolution)
     - *タイトル*: 「クレジットカード明細、視聴履歴の安全性。紳士のプライバシーを守る3つの鉄則」
     - *中身*: GoogleのE-E-A-Tを意識し、徹底したセキュリティ、匿名性、家族にバレない運用の技術解説。
- **送客CTA（Call to Action）のデザイン**:
  - 記事末尾のCTAは、四角く太いゴールド（`#D4AF37`）のボタン。ホバーするとリッチブラック（`#121212`）に反転。
  - コピーは**「AIコンシェルジュに今夜の気分を伝えて、あなた専用の裏メニューを出力する（無料）」**に統一。

### ② 信頼の盾：`vodnavi.jp`（Next.js / `site-brand/`）
GoogleのE-E-A-T（専門性・権威性・信頼性）を担保し、検索上位および事業の法的安全性を維持するための「公式の顔（身元引受人）」である。

- **実装方針**:
  - WordPressではなく、`app.vodnavi.jp` と同じ Next.js モノレポ内に `site-brand/` として軽量構築。Vercelで一体運用する。
  - Apple公式サイトのような、広大な余白（リッチブラック）に洗練されたプラチナホワイトの文字が浮かぶ「ミニマルテクノロジーデザイン」。
- **必須コンテンツ（E-E-A-T ハック）**:
  - **トップページ**: 次世代映像検索AI「VODNAVI」の解析精度の高さ、プライバシー完全保護の仕組みをインフォグラフィックで解説。
  - **ポリシーページ**: 「運営者情報（Safari株式会社等の法人格、またはプロジェクト運営委員会の明記）」「コンテンツ制作・査読ポリシー（AIと人間の専門家によるダブルチェック体制の明記）」「利用規約」「プライバシーポリシー」。
- **送客動線**:
  - ヘッダーの右上に、常に美しく明滅するゴールドのボタン **「AIコンシェルジュを起動（無料）」** を固定配置。

### ③ 成約の核心：`app.vodnavi.jp`（Next.js × AIチャット）
ユーザーの熱量が最高潮に達する、ファネルの最下流（成約エンジン）。

- **デザイン・レイアウト**:
  - 完全なダークモード。LINEのようなチープな吹き出しUIは厳禁。薄いグレー（`#1E1E1E`）のモダンなカードUIがタイムラインに流れる高級感。
- **流入インテントに応じたプロンプト動的最適化（URL設計の拡張）**:
  Moterist（集客）からAppへ遷移する際、従来の `source=moterist` に加え、読者の意図を識別する `intent` パラメータを付与する。
  - `?source=moterist&intent=beginner`: 挨拶文をビギナー向けに優しく、利用方法の案内を強化。
  - `?source=moterist&intent=actress`: 特定の女優やニッチジャンルを深掘りするプロンプトへ自動スイッチ。
  - `?source=moterist&intent=discount`: セールやお得情報、コスパ重視の提案ロジックを展開。
- **商品カード（FANZAアフィリンク）の仕様**:
  - CCO（ChatGPT）が生成した「この作品があなたの〇〇な感情を満たす理由（100文字）」の推薦文を添える。
  - 購入・詳細ボタン（CTA）は、最も購買意欲を刺激する **「FANZA公式で作品の詳細・サンプル映像を確認する（18禁）」** に統一。
- **【年齢確認の盾（リーガル防衛）】**: 18禁コンテンツの提案を行う性質上、`app.vodnavi.jp` へのアクセス直後、ユーザーに対して**18歳以上であることを確認するモーダルウィンドウ（年齢確認ゲート）の表示を義務付ける**。判定結果はクッキー（例：`vodnavi_age_verified=1` / 期限 1 年）に保持し、これが未通過の状態では **コンシェルジュ機能および `/api/concierge` 等の API 呼び出しを完全に遮断** する構造とせよ（Vercel / mixhost / FANZA いずれの規約 BAN も防止）。
  - **実装最低要件**：
    - 初回訪問時、画面全体を覆うモーダル（背景透過なし）で「18 歳以上ですか？」を尋ね、「はい」のみ通過させる。「いいえ」は外部の年齢制限案内ページにリダイレクト。
    - クッキー判定は **サーバー側（middleware）でも実施** し、未通過のリクエストは API ルートで 403 を返す（クライアント JS の改ざんでバイパスされないようにする）。
    - クッキー値の改ざん防止のため、HMAC 署名付きトークンまたは Vercel の `cookies()` API を使い、`HttpOnly` 不可だが `Secure` `SameSite=Lax` で発行する。
    - 年齢確認モーダルは『ビブリア・エロティカ』の世界観に従い、ダーク × ゴールド配色で組む。煽情的な画像を含めない。

## 4. 各AIの完全調律ルール（ガバナンス）

本ガイドラインを維持し、最短で月商100万円を達成するため、各AIは以下の運用プロトコルを自律的に実行せよ。

1. **CSO (Gemini 3)**: 本ガイドを長期記憶の核とし、発行するすべての `STRATEGY_BRIEF` が「ビブリア・エロティカ」の世界観およびE-E-A-T要件を満たしているか厳格に監査せよ。
2. **CTO (Claude Opus 4.7)**: `app-concierge/` の UI カラー、カードデザインを本仕様に即座に適合させよ。また、`site-brand/` のNext.jsスキャフォールドをこの骨組みで構築せよ。
3. **CCO (ChatGPT 5.5 + Image 2)**: 記事および画像を生成する際、「ピンク・ネオン・安易な露出」を封印し、「ゴールド・ダーク・知的なエロティシズム」に変換して出力せよ。OpenAIの規約BANを回避するため、直接的ワードを避け「シネマティックなライティング」「みずみずしい質感」等のサニタイズ表現を徹底せよ。
4. **週次データ駆動PDCA（トリガー設定）**: 毎週土曜日、CSO（Gemini）はGA4およびSearch ConsoleのデータをClaude Code経由で読み込み、KPIの進捗を監査、CVRや送客率（CTR_app）が低下している記事を特定、CCOへ自動的に「リライト指示書」を発行するルーティンを回せ。
5. **アフィリエイトマスターIDの厳格分離（ID汚染の盾）**: CCOおよびCTOは、記事コードやアプリソース内にアフィリエイトID（およびサブID）を**直接ハードコードすることを永久に禁止**する。すべてのIDは Next.js の環境変数（`NEXT_PUBLIC_FANZA_AFFILIATE_ID` 等）および WordPress 側の共通定数（`functions.php` または MU プラグインの `define('VODNAVI_FANZA_AFF_ID', ...)`）から動的に呼び出す構造を徹底せよ。
   - **理由**：ID 変更時に全記事・全コードを横断検索して書き換えるコストを排除し、ASP 移行・サブID 変更・成果地点の付け替えに **1 箇所の環境変数更新だけで対応** できる状態を維持するため。フェーズ 2（DMM TV / U-NEXT 限定解放）への移行時にも、新 ASP の ID を環境変数に追加するだけで配線が完成する。
   - **禁則**：CCO が記事内 CTA URL に `af_id=` の値を直書きすること、CTO が `app-concierge/` 内で文字列リテラルとして ID を埋め込むこと、いずれも PR 拒否事由とする。
   - **抽象化**：CTO は `buildAffiliateURL({ asp, contentId, actressOrSku, ... })` のように **ASP 名 × 環境変数** で URL を組み立てるビルダ関数を新設し、すべてのリンク生成をここに通す。
