- **原因: 収集側。X のリストは投稿を落としていない。**
  - Chrome のタブが背景状態（`document.visibilityState = "hidden"`）のとき、JS の `scrollBy` でページを送っても X の仮想化タイムラインは新しい投稿を描画しない。実測: JS で y=11,800 まで送っても取得件数は 7 のまま増えなかった。

- **帰結**: リスト方式を使う場合は実スクロール入力（スクリーンショット付きで重い）が要る。プロフィール直読みは 1 アカウントずつ navigate するため初回描画で拾え、背景タブでも機能した（ただし各アカウントの直近 3〜5 件程度が上限）。どちらを主にするかは CSO 裁定事項。
