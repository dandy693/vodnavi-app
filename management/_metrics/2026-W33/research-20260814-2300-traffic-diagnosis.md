# 2. Phase 1 実測 — on-page（本番 HTML の実取得）

## 2-1. 【重大・時間制約あり】配信予定の X 投稿が 404 の URL を指している

**`https://app.vodnavi.jp/works/videoa/ebwh00359` は HTTP 404**（**3回連続で確認・3/3**）。

- **この URL は Airtable `recfiiHpFmz8h4wZC`（B8 T1改 園田茉莉華 デビュー作）の `リンクURL` であり、`承認済`・予約日時 2026-08-17 21:00 JST で配信待機中である**（第28便で CTO が承認・設定した）。
- **main sitemap にも archive sitemap にも収録されていない**（`grep` 0件）。
- 同時に配信予定の他4件は **すべて HTTP 200**（`snos00321` / `roe00535` / `mdvr00434` / `urvrsp00599`）。

**本便は Airtable への書き込みが禁止されているため、対処していない。CSO の判断を要する。**

**ガードが検出できなかった理由（事実）**: `g3_link_is_works` は **URL のパス形式のみを検査**しており、**リンク先が実在するか（HTTP ステータス）は検査していない**。第29便の全件走査でも同様（走査は行のデータのみを見る）。

## 2-3. title / description

- **`canonical` は全ページに存在**。`robots` は 200 応答が `index, follow`、404 が `noindex`、`/lp` が `noindex`。**noindex の乱用は無い**（§2 に適合）。
- **記事A のみ meta description がタイトル由来（38字）**。原因は `editorial_articles.description` が **NULL** で、`generateMetadata` の fallback（`page.tsx:80-82`）が `compactDescription(article.title)` を返すため。他7記事は 91〜119字の固有 description を持つ。
- works / genres は description が**全て140字ちょうど**（テンプレートの切り詰め上限）。
- title の重複は**404ページとトップが既定文言を共有している**ことによるもので、**インデックス対象ページ間の重複は無い**。
