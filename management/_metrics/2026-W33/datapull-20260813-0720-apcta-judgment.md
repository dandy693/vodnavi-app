# 取得方法の記録（再現性のため）

GA4 の URL パラメータは、**トップレベルではなく `params=` の中に URL エンコードして入れる**と機能する（トップレベルに置くと `intelligenthome` へリダイレクトされる）:

```
#/a355462253p489519780/reports/explorer?params=_u..nav%3Dmaui%26_u.comparisonOption%3Ddisabled
  %26_u.date00%3D20260806%26_u.date01%3D20260812%26_r.explorerCard..rowsPerPage%3D250
  &r=all-pages-and-screens
```

- **`_u.date00` / `_u.date01` / `_r.explorerCard..rowsPerPage` は `params=` 内で機能する**
- **`_r.explorerCard..filterTerm` は `params=` 内・外いずれでも機能しない**（`intelligenthome` へ弾かれる）→ **絞り込みではなく全行走査で対応した**
- 日付ピッカーの**カレンダー日付クリックと入力欄への `type` はいずれも着地しなかった**（§10 の事象）。**URL パラメータ経由が唯一機能した経路**
