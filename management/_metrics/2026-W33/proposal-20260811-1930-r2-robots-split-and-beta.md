### 観測計画（+2週 中間 / +4週 判定）→ **汚染される**

R2 の判定指標は **「代替canonical 2,000」と「amateur 構成比 91.2%」**（`T-20260813-R2-EXEC` の観測計画）。

**Concierge パラメータURL は canonical が `/concierge` へ集約されている**（第3便実測）。GSC 上これは **「代替 canonical タグがあるページ」に分類される**＝**R2 の判定指標そのものに乗っている**。

robots.txt で Disallow すると、これらは時間をかけて **「robots.txt によりブロックされました」へ移動**し、**R2 と無関係に代替canonical が減る**。

### 汚染量の定量（§4「予測は既知の残存要因を定量的に織り込む」に従う）

| 項目 | 値 |
|---|---|
| 実測（第3便・GSC ドリルダウン） | **842件中 59件 = 7.0%** が concierge パラメータURL |
| **不確実性** | この 842 は R2 の基準線 **2,000** と**分母が一致しない**（測定日・レポート種別が異なる）。外挿には幅がある |
| **下限**（842 が全件で、concierge が全部そこに含まれる場合） | **59件** |
| **上限**（7.0% を 2,000 に外挿） | **約140件** |
| R2 の狙い（amateur 構成比 91.2% × 2,000） | **約1,824件** |
| **汚染の相対規模** | **3.2% 〜 7.7%** |

**【方向が問題】robots による減少と R2 による減少は同方向（どちらも代替canonical を減らす）。したがって統合すると R2 の効果を過大評価する。**

これは Q の失敗パターンの再演にあたる（`FACT_GOVERNANCE.md` §4: 予測が残存要因を定量化していなかったため不支持となった）。
