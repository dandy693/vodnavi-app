# Phase-2 ファーストビュー 実機幅(390px) 視覚監査

対象: PR #56 マージ後の本番 `app.vodnavi.jp/works/videoa/lulu00423`（GA4 実測の第1流入ページ）。Chrome を 390x844 にリサイズして本番レンダリングを目視。

## 監査結果

### ✅ 監査基準②（昇格ブロックの描画健全性）: 合格
H1（作品タイトル）直下の昇格ブロックは**崩れ・横はみ出し・サイレント障害なく正しく描画**:
- **金CTA**: 「FANZA公式で今すぐ視聴・サンプルを見る（18禁）」＋右矢印。シャンパンゴールド(#D4AF37)・全幅・角丸（`detail_fv_cta`）。
- **回遊ハブピル**: 1行で wrap、はみ出しなし。`九井スナオ`（女優、人物アイコン＋金枠）/ `ハイビジョン` `4K` `独占配信` `コスプレ`（ジャンル）。本作は女優1名のため女優1＋ジャンル4が表示（仕様: 女優最大3・ジャンル最大4）。
- 既存 in-flow の出演/ジャンル Field、sticky 下部バーも無改変で併存（複製昇格が成立）。

### ⚠️ 監査基準①（絶対ゼロ座標のFV内にCTA視認）: 条件付き未達 — 重要
**スクロール0px（絶対ゼロ座標）では金CTAは視認できない**。理由は構造的:
- DOM 順が `画像(3:4) → H1 → 昇格ブロック`。390px 幅では 3:4 商品画像の高さ ≈ 480px となり、ヘッダー(~56px)＋パンくず(~40px)＋画像でモバイルFV(844px、実描画~693px)をほぼ占有。
- 結果、ゼロ座標で見えるのは「ヘッダー / パンくず / 巨大な商品画像 / 既存sticky下部バー(`今宵ひらく`・`司書に相談`)」のみ。**H1 と昇格CTAは画像の直下＝1スクロール下**にある。
- 昇格ブロックは**わずかな下スクロールで即視認**でき、描画は完璧。ただし「3秒の視界＝ゼロ座標」の本来要件には、画像が壁になっている。

## 結論と次アクション（grounded）
- PR #56 の昇格ブロックは**描画・審美・分離計測(`detail_fv_cta`)とも正しく本番 live**。in-flow CTA(price直下)よりは確実に上へ昇格した（メタ/作品情報の上）。
- ただし **GA4 が示した「3:4画像がモバイルFVを占有」問題は画像自体が原因**で、H1直下への昇格だけでは絶対ゼロ座標には届かない。真にゼロ座標へ載せるには次のいずれかが必要（次スプリント候補・別PR）:
  1. 昇格ブロックを**画像より上**（H1ごと画像の前）へ配置、または
  2. モバイルで**商品画像の高さを上限化**（例: `max-h` + 余白確保）して画像が縦を食い尽くさないようにする。
- 現状でも既存 **sticky 下部バーがゼロ座標で金CTAを供給**しているため、モバイルCTAの可視性は二重化されている（昇格ブロック＝スクロール直後、sticky＝常時）。
