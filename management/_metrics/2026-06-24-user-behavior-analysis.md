## 3. 検索露出をアクセス数へ変えるための次なる攻性対策（M-06/M-07連動）

### 3-A. 検索流入の実態（Search Console 実測 / 28日）
- 総オーガニック: **クリック 1,640 / 表示 44,570 / CTR 3.68% / 平均掲載順位 9.30 / クエリ数 2,238**。
- 上位10クエリは **全件が作品タイトル/品番系**。最上位単独で 160クリック（全体の9.76%）:
  1. 「オフパコ枕営業している巨乳コスプレイヤーに…九井スナオ」160click / 1,274imp / CTR 12.56% / 順位 6.47
  2. 「アニメ版『入り浸りギャルに…話＃3・＃4』」68 / 1,041 / 6.53% / 6.70
  3. 「七沢みあ10タイトル！大放出！12時間 best」30 / 1,197 / 2.51% / 6.06
- **確定診断**: 流入は「特定タイトルを既に知っている指名検索」が支配的（既知メモリと再確認一致）。女優名・ジャンル名等の一般探索クエリは上位に不在＝ハブ（女優/ジャンル）への検索流入は現状ほぼ無い。

### 3-B. 生データから導く確定アクションプラン
1. **ハブ動線を「3秒の視界」へ引き上げる（最優先）**: 作品詳細の平均滞在は **1〜6秒**。M-06/M-07 で配線した女優/ジャンルへの内部リンクは有効だが、**フッター（90%スクロール=到達率4.6%）には人間はほぼ届かない**。M-07フッターのリンククラウドの第一価値は**クローラー向けPageRank供給（=SEO構造）であり、人間の回遊導線ではない**と切り分けるべき。人間の回遊を取るには、作品詳細の**ファーストビュー内**（タイトル直下〜本文冒頭）に女優/ジャンルハブと金CTAを配置する必要がある。
2. **金CTAをファーストビューに昇格**: 金CTAクリックは対ユーザー 7.55%。離脱が3秒で起きる以上、CTAが折返し下にあると大半に見られない。ファーストビュー内CTA化で初期母数の底上げを狙う。
3. **コンシェルジュの発見性を是正**: 起動率 0.79%（30人）と極小。導線（concierge_entry_click 27人）がそもそも見られていない。作品詳細ファーストビューへのエントリ昇格を検討。
4. **計測の穴を塞ぐ（次スプリント前提作業）**: (a) scroll 25/50/75 のカスタム閾値送信、(b) ai_affiliate_click への placement パラメータ（header/body/footer）付与、(c) 年齢ゲート専用イベント、(d) 作品→ハブ遷移の専用イベント。これらが無い限り、本レポートの空欄項目は次回も埋められない。
