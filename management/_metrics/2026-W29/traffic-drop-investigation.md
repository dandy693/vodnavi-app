### 判定: **複合 (H1 + H2)** — ただし H2 は「インデックス起因」ではない
1. **H1 成分 (bot減衰・想定内)**: Edge Requests (bot含む) は c237e51 (7/7 21:30 JST) 以降ピーク帯消失。GA4 (人間) が横ばいだった期間はないため「純粋H1」は棄却だが、**FANZAクリック減のうち bot 成分の減衰は Vercel リクエスト減で裏付けあり**。FANZA側 af_id別実数は未取得 (HUMAN)

3. **ただし H2 の深掘り結果、インデックス/ペナルティ起因は否定**: カバレッジ横ばい・手動対策なし・セキュリティ問題なし・sitemap成功・robots正常・全ページ200
4. **最有力の因果**: **FANZA API 400 障害 (7/6〜7/10・455件/155ユーザー・works/actresses/genres描画劣化) と減少期間が正確に一致**し、GSC表示は障害収束 (7/10) と同期して 7/9〜7/10 に回復、GA4 も 7/10 に回復。= 7/6〜7/9 の減少は「API障害による一時的な検索露出・UX低下」で説明可能
5. **残る未確定**: 7/11〜7/12 の GA4 再低下 (79/46)。この2日は Vercel エラー0・サイト正常・GSC未反映。週末効果を考慮しても 7/12=46 は過去日曜比 -48〜-59% で説明不足
