# STRATEGY BRIEF 103 — タスクボードの物理集約およびガバナンス統合

## 1. 目的
2026-06-30付で発生したインフラ・SOP関連タスクと、新章（Next.jsメディア構築および proxy.ts による年齢確認統合）のタスクがボード上で**3セクションに分散**している状態を解消し、一元管理による執行速度の最大化を図る。

## 2. 統括方針
- 分散していた「2026-06-30」セクション（ENV/SOP/MW・IDX・EDGE/UI）を最上部の単一ブロックへ **in-place で一本化**（既存 1,000 余行の履歴は一切破壊しない）。
- `proxy.ts`（年齢確認クッキー検査）と FANZA 早期クッキー着火（`buildEarlyCookieURL`・4つの盾の一つ `buildAffiliateURL` 系）の**混同禁止**を明文化した状態でタスクを追跡する。
- 凍結された `moterist.com`（`?source=moterist`）からの流入識別を計測可能にするための GA4 ホスト名／カスタムディメンション解析要件を、各タスクの達成条件に内包する。

## 3. 集約の物理規約（不変条件）
- TASK_BOARD.md の集約は **Edit（in-place）のみ**で行い、`cat > file` / `mv tmp file` 等の全文上書きパターンは**永久禁止**（過去の governance log・BRIEF ログ・全 T-XX の消失を防ぐ）。
- タスク ID は board 全体で**一意**。既存 ID への別内容の再割当（例: `T-20260630-MW` の二重定義）は禁止し、衝突時は新 ID へ改番する。
