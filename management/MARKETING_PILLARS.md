# MARKETING PILLARS — Moterist の3本柱と誘導動線

Moterist (moterist.com) は VODNAVI-GROUP の**集客拠点**。雑多に書くのではなく、**3 本のキーワード柱**に集中することで、ドメインの専門性 (E-E-A-T) を積み上げ、コンシェルジュ App への質の高い送客を作る。

## 設計思想

- **Moterist = 心理学・教養を装った VOD 動線**。直接「VOD おすすめ」を狙わず、ユーザーの「今夜何を見るか」という意思決定の**手前の感情**を捕まえる。
- 各柱は独立した SEO クラスター（10〜30 記事規模）として育てる。
- すべての記事末尾 CTA は `https://app.vodnavi.jp/concierge?source=moterist` に統一（[STRATEGY_BRIEF_001](./STRATEGY_BRIEF_001.md)）。
- 柱の選定は **「検索ボリュームがある × 商業意図と地続き × 心理/教養として書ける」** の三角形で決める。

## 3 本柱

### 🌑 柱 1：感情ナビ — 「今夜の気分で選ぶ作品」

**狙うクラスター**：ユーザーの**今の感情**を起点にした検索を捕まえる。

- ターゲットクエリ例：
  - 「失恋 立ち直り 映画」
  - 「眠れない夜 おすすめ」
  - 「達成感 ほしい ドラマ」
  - 「自己肯定感 上がる 映画」
  - 「泣きたい時 作品」
- 想定読者：明確に作品名を決めていない、感情ベースで探す層（VOD 流入層のボリュームゾーン）。
- コンシェルジュへの接続：感情ラベルを `source=moterist` の system addendum で活かし、「今〇〇な気分とのことですね」から提案開始。

### 📚 柱 2：教養レンズ — 「心理学・哲学・行動経済学で映画を読む」

**狙うクラスター**：話題作・名作を**学問のレンズで再解釈**する記事群。

- ターゲットクエリ例：
  - 「ジョーカー 心理学」
  - 「ショーシャンクの空に 意味」
  - 「(話題作) 解説 行動経済学」
  - 「ナラティブセラピー 映画」
  - 「自己実現 映画 ロールモデル」
- 想定読者：知的好奇心の強い層（25〜45 歳、AI コンシェルジュとの親和性が極めて高い）。
- コンシェルジュへの接続：「この記事を読んだ方にはこういう作品も」という導線で、教養トーンを保ったまま提案へ繋ぐ。

### 🌙 柱 3：シチュエーション最適化 — 「ひとり時間 / 週末 / 深夜」

**狙うクラスター**：時間・状況からの作品検索を捕まえる。

- ターゲットクエリ例：
  - 「一人暮らし 週末 映画」
  - 「深夜 1 人で見る ドラマ」
  - 「90 分以内 映画」
  - 「在宅ワーク 集中前 短編」
  - 「金曜の夜 ご褒美 作品」
- 想定読者：可処分時間が明確に決まっていて、ハズしたくない層。CVR が最も高くなる仮説。
- コンシェルジュへの接続：時間・気分・人数のヒアリングをスキップして、即提案フェーズに入れる。

## 柱ごとの記事フォーマット

すべての柱で共通の構成。CCO はこのテンプレに従って記事を生成する。

```markdown
# {タイトル}（H1）

> #PR / 本記事にはアフィリエイトリンクが含まれます。
> 配信状況は各公式サイトでご確認ください。

## 導入（150〜200字）
- 読者の感情・状況に強く共鳴する一段落。
- 結論を先に置く（この記事で何が分かるか）。

## 本文（H2 × 3〜5）
- 心理学 / 教養 / シチュエーションの観点で 1 セクション。
- 具体的な作品名は 3〜7 本を限度に。網羅より精度。

## まとめ（80〜120字）
- 読者への一言の労い + 次の行動への橋渡し。

## 今夜、AIコンシェルジュに「もう少し詳しく」を任せる
本記事で紹介した感情・状況をそのまま AI コンシェルジュに伝えると、
あなたの今の気分に合う作品をさらに絞り込んで提案します。

→ [VODNAVI コンシェルジュに相談する](https://app.vodnavi.jp/concierge?source=moterist)
```

### 各柱で意識する差分

| 柱 | トーン | 平均文字数 | CTA 文言 |
| --- | --- | ---: | --- |
| 感情ナビ | 寄り添い・低圧 | 2,000〜3,000 字 | 「今の気分のまま、コンシェルジュへ」 |
| 教養レンズ | 知的・落ち着き | 3,000〜5,000 字 | 「読み終えた余韻のまま、次の一本を」 |
| シチュエーション | 即決・実用 | 1,800〜2,500 字 | 「今夜の 90 分、迷わない」 |

## 誘導動線（記事 → コンシェルジュ）

### 1. ファーストインプレッション
- 記事冒頭の `#PR` 表記直下に、控えめなコンシェルジュ案内バナー（CCO がデザイン）。
- ただし強引な CTA は出さない。**記事価値を読ませてから誘導**するのが Moterist の方針。

### 2. 本文中導線
- H2 セクション 2〜3 個目あたりに「気になる作品が見つからなければ →」の柔らかい横導線を 1 箇所だけ。
- 多発は読者体験を壊すので NG。

### 3. 記事末尾の確定 CTA（最重要）
- 上記テンプレ末尾セクションを必須化。
- URL は `https://app.vodnavi.jp/concierge?source=moterist`（厳守）。
- ボタンの背景は VODNavi ブランドカラー（ダーク × ゴールド）に統一して、ブランドの一貫性を持たせる。

### 4. 関連記事ブロック
- 同じ柱の関連記事 3 本＋他柱から 1 本、の計 4 本を末尾に。
- 「コンシェルジュへ」と「関連記事」は**並列に並べない**（同じファーストビューに 2 CTA は禁忌）。

## ピラー & クラスター構造

各柱はピラー記事 1 + クラスター記事 N で組む。

```
[柱 1: 感情ナビ]
  ├─ ピラー記事: 「気分で映画を選ぶ完全ガイド」
  ├─ クラスター: 失恋 / 眠れない / 達成感 / 不安 / ...（各 1 記事 = 1 感情）
  └─ すべて末尾 CTA → ?source=moterist

[柱 2: 教養レンズ]
  ├─ ピラー記事: 「映画で学ぶ心理学入門」
  └─ クラスター: 各学派・各概念 × 代表作品

[柱 3: シチュエーション]
  ├─ ピラー記事: 「シーン別おすすめ作品の選び方」
  └─ クラスター: 一人時間 / 週末 / 深夜 / 在宅 / ...
```

各クラスター記事はピラー記事へ、ピラー記事は他柱のピラーへ内部リンクで繋ぐ。

## 守る線（やらないこと）

- 「VOD 比較」「動画配信 ランキング」等の**正面の商業クエリ**を Moterist で狙わない。そこは VODNavi 側の役割。
- 作品ジャケット画像を Moterist 側で直接ホストしない（権利・成人向け混在リスク）。サムネは AI 生成オリジナル or 抽象画像で。
- アダルト要素を Moterist の本文に持ち込まない（AdSense / 教養媒体としてのトーン維持）。成人コンテンツへの接続は Concierge App 側に閉じる。
