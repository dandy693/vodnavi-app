**根拠**: 第116便 補遺16（CSO裁定 2026-09-04）／固定条項の正典 → `FACT_GOVERNANCE.md` §21・§21-5・§21-5-1
**【厳守】§21 の固定変数（静止画スライドショー形式・手動投稿・006直リンク・#PR・判定基準）は不変。** **3本すべて同一の生成方式で統一する。**

## 0. フロー（3本共通）

**ひでき素材DL → CTO へ渡す → CTO 生成 → ひでき目視（1フレーム画像＋動画）→ ひでき投稿 → URL 報告 → CTO 記録**

**【厳守】投稿・素材取得・最終目視は HUMAN。** **X 投稿の自動化・Make/Airtable 経由化は行わない**（Phase 2 判定後の議題）。

## 1. ① 006 直リンクの発行（**ひでき実施**）

**発行は DMM アフィリエイトの「リンク作成ツール」で行う。CTO は値に触れない。**

| 項目 | 指定 |
|---|---|
| 登録サイト（af_id） | **`moterist-006`（x.com/vodnavi_jp）** |
| リンク先 | **対象作品の FANZA 作品ページ**（`al.*` 直リンク） |
| 形式 | **§21 集計定義に適合する形式**＝**X アナリティクスで「リンククリック」として計上される単一の URL**。短縮や中間ページを挟まない |

**【確認手順・厳守】発行後、リンク文字列に `moterist-006` が含まれることを目視すること。**
**【厳守】`moterist-990`〜`999` は API 専用であり人間向け CTA に使用禁止**（`FACT_GOVERNANCE` §8）。**`moterist-004` は app.vodnavi.jp 用であり、X には使わない。**

## 2. ② 投稿文の雛形（**3〜4行・#PR 込み**）

```
#PR

{作品名を短く}
配信開始まであと{N}日 / {収録}分 / {価格}円

▼作品ページはこちら
{006直リンク}
```

**【厳守】守ること**:

| # | 規則 | 根拠 |
|---|---|---|
| 1 | **`#PR` を必ず含める** | §21・`g4_pr_when_affiliate`（`al.*` 直リンクには #PR を要求） |
| 2 | **`#PR` 以外のハッシュタグを付けない** | X 運用の既定（`CLAUDE.md` の X 運用＝ハッシュタグなし） |
| 3 | **クーポン・%OFF・金額の割引表現を書かない** | §13 ガードレール5 |
| 4 | **誇大表現を書かない**（「絶対」「必ず」「最高」等） | §13 ガード（T3 の `g20` と同趣旨） |
| 5 | **見放題対象かどうかを書かない** | §5-2-3（API では判定できない・HUMAN 実査枠） |
| 6 | **価格は API 実測値をそのまま書く** | §15-2 軸4（実測のみ） |

## 3. ③ 投稿前チェックリスト（**ひでき実施・投稿ボタンを押す前**）

- [ ] **`#PR` が本文に入っている**
- [ ] **`#PR` 以外のハッシュタグが無い**
- [ ] **リンクに `moterist-006` が含まれることを目視した**
- [ ] **同日に他の直リンク投稿が無い**（§13「直リンクは1日1件まで」）
- [ ] **同日に T3 セール速報が出ていないか確認した**（出ていれば3件配信になる。§13-7-2 により 9/11 までは許容だが記録する）
- [ ] **動画の1フレーム画像3枚と動画本体を目視した**（豆腐化・はみ出し・意図しない描写が無い）
- [ ] **投稿予定時刻が 21:00 / 22:30 の既存枠と重複していない**（テキスト投稿側に干渉しない）

## 4. ④ 投稿後の報告様式（**ひでき → CTO**）

```
Phase 1 動画 {n}本目
投稿URL: https://x.com/vodnavi_jp/status/{ポストID}
投稿時刻: 2026-09-XX HH:MM JST
対象作品: {content_id}
```

**CTO 側の記録**: **ポストID から snowflake で実配信時刻を復元し、`management/_metrics/` へ記録する。** **X アナリティクスのリンククリック率は 9/12 判定時にまとめて取得する**（§21-1・**GA4 ではなく X アナリティクスが正**）。
