## 2. ② 投稿文の雛形（**3〜4行・#PR 込み**）

```
#PR

{作品名を短く}
配信開始まであと{N}日 / {収録}分 / {価格}円

▼作品ページはこちら
{006直リンク}
```

**【厳守】守ること**:

| # | 規則 | 根拠 |
|---|---|---|
| 1 | **`#PR` を必ず含める** | §21・`g4_pr_when_affiliate`（`al.*` 直リンクには #PR を要求） |
| 2 | **`#PR` 以外のハッシュタグを付けない** | X 運用の既定（`CLAUDE.md` の X 運用＝ハッシュタグなし） |
| 3 | **クーポン・%OFF・金額の割引表現を書かない** | §13 ガードレール5 |
| 4 | **誇大表現を書かない**（「絶対」「必ず」「最高」等） | §13 ガード（T3 の `g20` と同趣旨） |
| 5 | **見放題対象かどうかを書かない** | §5-2-3（API では判定できない・HUMAN 実査枠） |
| 6 | **価格は API 実測値をそのまま書く** | §15-2 軸4（実測のみ） |

### 5-3. 【厳守】**当日生成ルール**（ひでき指定 2026-09-04）

> **動画の生成は「投稿日当日」に行う。前日以前に作らない。**

- **理由**: **動画にカウントダウン（「あと N 日」）を焼き込むため、生成日と投稿日がずれると日数表記が誤る。**
- **実装**: **カウントダウンの基準日は、スクリプトが実行時に JST の当日 00:00 を自動で取る。** **ハードコードしない。**
- **`--asof YYYY-MM-DD` で基準日を上書きできるが、その場合はスクリプトが警告を出す。** **通常は使わない。**
- **ガード**: **`あと N 日` の N が 1 未満になる場合、スクリプトは生成せずに中止する**（発売日を過ぎた作品でカウントダウンを作らないため）。
- **生成時に「基準日」と「あと N 日」を必ずログに出す。** **投稿前チェック（§3）で、この N が投稿日と整合するか目視すること。**

**【併記・2026-09-04 に修正した表示バグ】JST の日付を出すときに `toISOString()` の結果をそのまま使わないこと。** **`2026-09-04 00:00 JST` は UTC では `2026-09-03 15:00` であり、`toISOString().slice(0,10)` は `2026-09-03` を返す。** **基準日を1日ずらして表示してしまう。** **`+9h` してから `slice` すること。**

### 5-4. 【2026-09-05 追加】はみ出しの機械チェックは **scene1 を含める**

**それまでの実装は scene2 / scene3（テキストスライド）しか検査しておらず、scene1（パッケージ画像 + タイトル帯）を見ていなかった。**
**その状態で「はみ出しなし」と報告していたが、1本目 `1sun00067a` は実際にはタイトルがはみ出していた**（→ `PHASE1_VIDEO_LOG.md` 2本目の節）。

- **検査方法**: scene1 は背景がパッケージ画像のため全面では閾値が使えない。**タイトル/出演の帯（y=1580..1810）に限定し、左右 4px の端の YMAX を見る。** 閾値は同じ 60。
- **【厳守】「機械チェックが OK」は「検査した範囲で OK」でしかない。** **検査していない範囲について「なし」と書かない**（§10 / §11 分類D）。
- **【既知の構造的問題】タイトルは 26字で切り詰め fontsize 44 で描画される。全角26字 ≒ 1,144px + `boxborderw` 48px ＝ 約1,192px で、画面幅 1,080px を必ず超える。** **タイトルが長い作品では常に発生する。** **切り詰め長・フォントサイズの変更は §21-5-1 の統一条項に触れるため CSO 裁定を要する。**
- **候補選定時の予防**: `pick3.mjs` は候補ごとに `titleWidthPx` と `titleOverflow` を算出する。**1,080px を超えない候補を選べば、仕様を変えずに回避できる。**
