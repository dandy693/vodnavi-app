## 1. アカウント作成（HUMAN）

1. `https://bsky.app` を開き「アカウントを作成」。ホスティングは既定（Bluesky Social）のまま。
2. メールアドレス・パスワード・生年月日を入力（**生年月日は実際の値。** 成人向け表示の設定は年齢要件があると見られる＝CTO は画面で未確認。有効にできなければその旨を報告）。
3. ハンドルを入力（§0 で決めたもの）。
4. 届いた確認メールでメールアドレスを確認する。
5. **パスワードはパスワード管理ツールに保存。** 2 要素認証（メール）を「設定 → アカウント」で有効化できる場合は有効化する（画面の項目名は変わりうる。見つからなければ「未設定」と報告）。

## 2. 成人向けコンテンツの設定（HUMAN）

Bluesky の仕組み（公式ドキュメント `docs.bsky.app/docs/advanced-guides/moderation` の要旨）:
- **成人向けの区分は「投稿ごと」に付ける自己ラベル**（投稿画面の盾アイコン → 「Suggestive / Nudity / Porn」）。
- **プロフィールに付くラベルはアバター等のプロフィール情報にのみ効き、投稿を隠すものではない。**
- **成人向けの投稿をラベル無しで繰り返すと、Bluesky がアカウントを制限することがある。**

したがって本準備で行うのは次の 2 点のみ:
1. **「設定 → モデレーション（Moderation）→ コンテンツフィルター」で「成人向けコンテンツを有効にする」を ON。** 各区分（Porn / Nudity / Suggestive）の表示を「警告付きで表示」にする。**これは自分の閲覧側の設定であり、自分の投稿のラベルではない。**
2. **投稿時のルール（将来・投稿開始時に適用）**: 作品を扱う投稿は、画像の有無にかかわらず**必ず自己ラベルを付ける**（区分の選び方は投稿開始の裁定で決める）。**本準備では投稿しない。**

## 4. 完了報告（HUMAN → CTO）

次の値だけを Claude Code に貼る（**パスワード・コード類は貼らない**）:
- ハンドル（`@…`）
- プロフィール URL（`https://bsky.app/profile/…`）
- 2 要素認証の有効化（済／項目なし）
- 成人向けコンテンツ設定（ON にしたか）

CTO は受領後、プロフィール URL を読み取りのみで開き、表示名・リンク・アバターが上表どおりかを確認して記録する（**CTO はログイン・操作しない**）。
