# Bluesky アカウント準備手順（HUMAN 作業・投稿はしない）

> **起案**: CTO（2026-09-29・CSO裁定 2026-09-29 の 4／FACT §26-14）
> **範囲**: アカウント作成・成人向けコンテンツの表示設定・プロフィールまで。**投稿・フォロー・リプライ・リンク付きの告知はしない**（開始は 10/12 判定後の別裁定）。
> **【厳守】パスワード・確認コード・アプリパスワードの値は、チャット・リポジトリ・Airtable に書かない。パスワード管理ツールにのみ保存する**（§13-0・§27-4 と同じ原則）。CTO はアカウントの値に触れない。

## 0. 事前に決めておくこと（CSO）

| 項目 | 候補 | 備考 |
|---|---|---|
| ハンドル | `vodnavi.bsky.social` 等 | 独自ドメイン（例 `vodnavi.jp`）をハンドルにするのは **DNS 変更を伴うため今回はしない**（別裁定） |
| 表示名 | 「VODNAVI｜ビブリア・エロティカ」（X と同じ） | X と揃えるかは CSO |
| 登録メール | 専用のアドレス | X 用と分けるかは CSO |

## 1. アカウント作成（HUMAN）

1. `https://bsky.app` を開き「アカウントを作成」。ホスティングは既定（Bluesky Social）のまま。
2. メールアドレス・パスワード・生年月日を入力（**生年月日は実際の値。** 成人向け表示の設定は年齢要件があると見られる＝CTO は画面で未確認。有効にできなければその旨を報告）。
3. ハンドルを入力（§0 で決めたもの）。
4. 届いた確認メールでメールアドレスを確認する。
5. **パスワードはパスワード管理ツールに保存。** 2 要素認証（メール）を「設定 → アカウント」で有効化できる場合は有効化する（画面の項目名は変わりうる。見つからなければ「未設定」と報告）。

## 2. 成人向けコンテンツの設定（HUMAN）

Bluesky の仕組み（公式ドキュメント `docs.bsky.app/docs/advanced-guides/moderation` の要旨）:
- **成人向けの区分は「投稿ごと」に付ける自己ラベル**（投稿画面の盾アイコン → 「Suggestive / Nudity / Porn」）。
- **プロフィールに付くラベルはアバター等のプロフィール情報にのみ効き、投稿を隠すものではない。**
- **成人向けの投稿をラベル無しで繰り返すと、Bluesky がアカウントを制限することがある。**

したがって本準備で行うのは次の 2 点のみ:
1. **「設定 → モデレーション（Moderation）→ コンテンツフィルター」で「成人向けコンテンツを有効にする」を ON。** 各区分（Porn / Nudity / Suggestive）の表示を「警告付きで表示」にする。**これは自分の閲覧側の設定であり、自分の投稿のラベルではない。**
2. **投稿時のルール（将来・投稿開始時に適用）**: 作品を扱う投稿は、画像の有無にかかわらず**必ず自己ラベルを付ける**（区分の選び方は投稿開始の裁定で決める）。**本準備では投稿しない。**

## 3. プロフィール（HUMAN）

| 項目 | 内容 | 注意 |
|---|---|---|
| アバター・バナー | **自社ブランド画像のみ**（`https://app.vodnavi.jp/opengraph-image` と同系統） | **作品のパッケージ画像・サンプル画像は使わない**（X のセンシティブラベルの教訓・§26-14） |
| 自己紹介 | 18 歳以上向けであること・サイトの説明（事実のみ） | 割引額・クーポン・「無料」等の訴求は書かない（§13 の鉄則） |
| リンク | **`https://app.vodnavi.jp/?utm_source=bluesky&utm_medium=social&utm_campaign=profile`** | **アフィリエイトリンク（`al.*`・af_id）は置かない。** DMM アフィリエイトで Bluesky は**サイト登録されていない**（登録済みは 001〜006・§8）。遷移元はパラメータでしか計測できない（§3-1） |

## 4. 完了報告（HUMAN → CTO）

次の値だけを Claude Code に貼る（**パスワード・コード類は貼らない**）:
- ハンドル（`@…`）
- プロフィール URL（`https://bsky.app/profile/…`）
- 2 要素認証の有効化（済／項目なし）
- 成人向けコンテンツ設定（ON にしたか）

CTO は受領後、プロフィール URL を読み取りのみで開き、表示名・リンク・アバターが上表どおりかを確認して記録する（**CTO はログイン・操作しない**）。
