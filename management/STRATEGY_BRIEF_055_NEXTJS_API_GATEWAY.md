# STRATEGY BRIEF 055: Next.js遷都期における拡張API検証ゲートと本番同期プロトコル

- **ステータス**: APPROVED (CSO 策定 / 統括ガバナンス)
- **策定日**: 2026-06-09
- **対象ドメイン**: vodnavi.jp / app.vodnavi.jp
- **関連**: `STRATEGY_BRIEF_053_PREVIEW_ENV_SYNC.md` / `STRATEGY_BRIEF_054_INFRA_ENVIRONMENT_POLICY.md`

## 1. 目的と背景

`BRIEF_054` で確定した「環境変数スコープ同期（計測タグを除く）」および `BRIEF_053` のプレビュー不整合の解決を受け、Next.js への遷都に際して FANZA / DMM TV / U-NEXT 等のマネタイズ API が本番・プレビュー環境双方で「正常に成約リンクを生成できるか」を自動的・構造的に保証する。

## 2. 拡張API検証ゲートの要件

1. **ランタイム疎通テストの自動化**:
   - プレビュー環境ビルド時、またはデプロイ後のヘルスチェックにおいて、サーバーサイドでの API fetch（`DMM_*` 関連のシークレットを使用）が偽陽性（401/403 エラー）を起こさないか、CI/CD プロセス内で検証可能なガードを設ける。
2. **計測タグのカーブアウト運用の厳格化**:
   - `BRIEF_054` の例外処理（§2.4）に基づき、GA/GTM 等のフロントエンド計測タグは、Preview 環境では一律で `null` または `noindex` ガードが作動していることをビルドログ、あるいは `NODE_ENV` 判定によってトリガーすること。

## 3. マネタイズへの影響

本番環境でのみ動くべきタグと、プレビュー環境でも動くべきサーバーサイド API の挙動を厳格に分離することで、開発速度を落とさずに成約機会損失を抑止する。
