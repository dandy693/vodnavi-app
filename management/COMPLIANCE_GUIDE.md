VODNAVI-GROUP の 3 サイト（Moterist / VODNavi / Concierge App）すべての公開ページが**最低限満たすべき**法令・規約・表示要件をまとめる。

> ⚠️ **重要**：本ガイドはあくまで運用上のチェックリスト・テンプレートであり、法的助言ではない。グレーゾーンや個別判断が必要なケースは、必ず弁護士・行政書士・各社サポート窓口に確認すること。

## 1. 日本の法令チェックリスト

### 1.1 景品表示法（景表法）

- [ ] **優良誤認・有利誤認**：「絶対」「業界No.1」「最安」等の断定表現は、根拠資料が手元にない限り使わない。
- [ ] **No.1 表示**：使う場合は調査主体・調査時期・対象範囲・調査方法を必ず近接して明記。
- [ ] **比較表示**：他社サービスとの比較は公平・客観的に。古い情報をそのまま掲載しない。
- [ ] **打消し表示**：例外条件・別途料金・適用除外を本文と同じ視認性で記載。小文字で隠さない。

### 1.2 ステルスマーケティング規制（2023.10〜 景表法告示）

- [ ] **広告表示の明示**：アフィリエイトリンクを含むページには `#PR` `#広告` または「本ページにはアフィリエイトリンクが含まれます」を**ファーストビュー or 記事冒頭に**明記。
- [ ] **個人感想の混在禁止**：体験談として書く場合、提供を受けた事実があれば明示。
- [ ] **SNS 投稿**：X / Instagram でアフィリ URL を含む投稿には `#PR` を必ず付与。

### 1.3 特定商取引法 / 表示義務

VODNAVI 自体が「物販事業者」に該当するかは形態次第。FANZA への単純送客アフィリエイトであっても、サイト運営者情報（運営者名・連絡先）の表示は信頼性確保の観点から必須。

- [ ] フッターまたは `/about` `/contact` から運営者情報にアクセス可能。
- [ ] お問い合わせ手段（メールフォーム or メールアドレス）を提示。

### 1.4 個人情報保護法

- [ ] **プライバシーポリシー**：Cookie / アクセス解析 / フォーム入力情報の取り扱いを記載した PP ページを `/privacy` 等で公開。
- [ ] GA4 を使う場合、IP 匿名化・Cookie 利用についてプライバシーポリシーで言及。
- [ ] お問い合わせフォーム（Make.com 経由含む）で取得した情報の利用目的を明示。

### 1.5 著作権法

- [ ] FANZA API から取得する商品画像・タイトル・あらすじは**API 利用規約の範囲内**でのみ表示（後述 §2.1）。
- [ ] 自作以外のスクリーンショット・引用は出典を必ず明記、引用要件（主従関係・必要最小限・明瞭区別）を満たす。
- [ ] サムネ画像を AI 生成する場合、実在の作品ジャケットを模倣しない。

### 1.6 青少年保護・年齢制限

FANZA は成人向けコンテンツを扱う。送客元（Moterist 等）の文脈と着地のミスマッチに注意。

- [ ] 成人向け商品を直接表示するページには年齢確認ゲート or 警告表示。
- [ ] Moterist 側からの送客時、CTA 文言で「成人向けコンテンツを含む」旨を示唆。
- [ ] スマホ実機で SafeSearch / フィルタリング下の表示崩れがないか確認。

### 1.7 薬機法・健康増進法（補助的）

VOD アフィリエイトの主戦場ではないが、Moterist の心理学・教養記事で**「治る」「効く」**等の効果断定を絶対に書かない。

## 2. 各社サービス規約チェックリスト

### 2.1 FANZA（DMM） アフィリエイトプログラム

公式ガイドライン：https://affiliate.dmm.com/

- [ ] アフィリエイト ID（通常 `-990` / `-996` 等）を正しい URL に付与している。
- [ ] **API 利用規約**：
  - 取得した商品データを許可された用途以外（再販・データ販売等）で使わない。
  - キャッシュ期間・更新頻度のルールがあれば遵守。
- [ ] **画像・タイトル**：FANZA から取得した素材を改変して別作品と誤認させない。
- [ ] **誇大表現禁止**：「100% 視聴できる」「無料でフル視聴」等の事実と異なる訴求をしない。
- [ ] **リンク偽装禁止**：アフィリ URL を一見別サービスに見えるよう加工しない。
- [ ] サイトに「本サイトは FANZA アフィリエイトプログラムに参加しています」旨を明記。

### 2.2 U-NEXT アフィリエイト（取り扱う場合）

A8.net / バリューコマース等の ASP 経由が一般的。各 ASP の個別規約に従う。

- [ ] 無料トライアル誘導時、トライアル条件（期間・自動課金・解約方法）を併記。
- [ ] 「無料」表記は条件付き無料の場合「初回○日間無料」と必ず限定する。

### 2.3 Amazon Prime Video / Netflix 等を扱う場合

- [ ] **Amazon アソシエイト**：商品リンク・画像の取り扱いは Amazon の公式 API / SiteStripe 経由のみ。商品価格を独自に書き換えない。
- [ ] Netflix は原則アフィリエイトプログラムを提供していない。リンクを貼る場合は単純な情報提供のみ。

### 2.4 Google AdSense（併用する場合）

- [ ] アダルトコンテンツ（FANZA 成人向け）と AdSense は同居不可。Moterist / VODNavi（一般向け）のみ AdSense 配置を検討、Concierge App とは混在させない。

### 2.5 Vercel / Anthropic API / Make.com 利用規約

- [ ] Anthropic API の Usage Policies に沿った用途で使用（性的搾取・違法行為支援等の禁止項目に該当しないか定期確認）。
- [ ] Vercel の Acceptable Use Policy（成人向けコンテンツの扱い）を確認。Concierge App が直接成人向けコンテンツを「表示」するのか「リンクするだけ」なのかで判定が変わる。
