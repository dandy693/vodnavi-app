# FANZA Evergreen Sale Hub Requirements

## Scope

- Target page: `post_id 954`
- Current URL anchor: `https://moterist.com/fanzaotoku/`
- Planning only. No production rewrite is executed from this document.

## Objective

Rebuild `954` from a seasonal campaign article into a durable `Evergreen Sale Hub` that can stay live year-round while only the campaign-specific block changes.

## Non-Negotiable Direction

### 1. Stop depending on seasonal campaign framing

- Do not anchor the page concept to year-end, New Year, summer, or one named campaign.
- The lead section must describe the page as a place to confirm current FANZA sale information, not as a permanent page for one event.
- Seasonal campaign names may appear only inside clearly dated update blocks.

### 2. Use a year-round heading structure

Recommended evergreen structure:

1. What this page helps you confirm now
2. How to check current FANZA sales safely
3. Types of offers that may appear
4. What to compare before clicking
5. Current campaign update block
6. Related guides
7. Final official confirmation CTA

## Required CTA Policy

### Sale confirmation CTA

- Primary CTA must tell users to confirm current sale information on the official FANZA page.
- CTA wording must avoid claiming a sale is active unless the page has been freshly updated and verified.
- CTA placement:
  - one primary CTA near the top
  - one repeated CTA after the current campaign update block
  - optional closing CTA at the end

### FANZA official confirmation path

- The page must visibly distinguish:
  - evergreen guidance
  - current campaign status that can change
- The user should understand that official confirmation is required for price, eligibility, and campaign timing.

## Replaceable Update Region

### Campaign swap area

Keep one explicit replaceable region for fast updates:

- current campaign name
- current campaign period
- eligible content or format scope
- notable caution or verification note
- current CTA label

This region should be replaceable without rewriting the rest of the page.

## Operational Rules

### Do not leave old sale facts behind

- Remove or archive stale campaign periods before publishing a new campaign block.
- Do not stack multiple outdated campaign summaries in the public body.
- If the current campaign is unknown, the page must fall back to evergreen guidance and official confirmation language only.

### Update ownership rule

- Any future campaign refresh must include:
  - campaign fact check date
  - source confirmation path
  - CTA wording review
  - stale copy removal check

## Internal Link Rules

- Keep links to `1095`, `1106`, and `994` as context and trust support.
- Add future links to genre hubs, actress hubs, or format guides only after those destinations exist and have durable intent.
- Do not overload the page ending with too many lateral links.

## CTA Measurement Requirements

- Track top CTA click.
- Track mid-page current-campaign CTA click.
- Track final CTA click.
- Track clicks into `1095`, `1106`, and `994` from this page.
- Keep a page-type label such as `evergreen_sale_hub`.
- If future analytics supports it, keep a campaign-block version label to distinguish evergreen shell performance from campaign swap performance.

## Risks

- strongest risk: the page looks current while carrying stale campaign detail
- secondary risk: actress links and sale intent get mixed into an unfocused page
- secondary risk: too many CTA variants reduce clarity

## Exit Criteria For Future Execution Phase

- evergreen shell copy defined
- replaceable campaign block format defined
- official confirmation CTA wording fixed
- stale-campaign cleanup checklist defined
- tracking events named
