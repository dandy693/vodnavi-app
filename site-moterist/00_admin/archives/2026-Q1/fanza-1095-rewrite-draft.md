# FANZA 1095 Rewrite Draft

## 1. 1095 Rewrite Policy

`1095` is a `Beginner Guide`.

Its job is:

- introduce FANZA to first-time or hesitant users
- lower lightweight anxiety
- make the next action understandable
- route the user toward the official CTA first

Its job is not:

- acting like a sale hub
- acting like a benefits-first page
- acting like a deep safety-resolution page

Therefore, this rewrite draft keeps `1095` explanation-first, beginner-first, and support-route aware.

## 2. Elements To Keep

- beginner-oriented explanatory structure
- official CTA as the main next step
- light reassurance tone
- support links to `1106 / 994 / 954`
- source-level exclusion of `1018`
- FAQ as a possible lightweight support layer

## 3. Elements To Weaken

- strong coupon-first or sale-first wording
- benefit-led wording that feels closer to `1106`
- sale-check phrasing that feels closer to `954`
- oversized reassurance that belongs more naturally to `994`
- FAQ answers that repeat the body too heavily

## 4. Removal Candidates

- any wording that creates a strong `今すぐセール` impression before onboarding is complete
- any stale campaign or coupon wording
- any support copy that visually or structurally competes with the official CTA
- any FAQ item that acts like a duplicate reassurance or duplicate sale block

## 5. Weakening Directions For `90%OFFクーポン`-Type Promo Wording

Recommended direction:

- do not use discount-led language as a primary hook on `1095`
- if sale awareness must remain, reduce it to a secondary note
- where possible, convert sale urgency into a soft route toward `954`

Weakening examples:

- avoid:
  - `初回購入限定！90%OFFクーポンはこちら→`
- prefer:
  - `開催中の特典やセール情報を確認したい場合は、最新案内を別ページで確認できます。`

Avoid:

- urgency-first coupon language
- dominant discount-first headings
- current-offer assumptions that belong to `954`

## 6. Route-Handoff Direction Toward `954 Evergreen Sale Hub`

If sale interest needs to be acknowledged on `1095`, handle it as a secondary route only.

Recommended handoff style:

- `セールやキャンペーン情報を確認したい方は、最新情報の確認ページへ進んでください。`
- `現在の特典や割引を見てから判断したい場合は、別ページで最新案内を確認できます。`

Intent:

- keep `1095` beginner-first
- move active sale intent toward `954`
- prevent role drift inside the beginner guide

## 11. FAQ Draft

### Q1

- `初めて使う前に何を確認しておくとよいですか？`

Draft answer:

`まずは、利用前に確認したい基本的な案内を順番に整理しておくと迷いにくくなります。細かな特典や変わりやすい情報は、最後に公式ページで確認する考え方で進めると分かりやすくなります。`

### Q2

- `不安が残る場合はどこを先に見ればよいですか？`

Draft answer:

`安全性や使い方に関する不安が強い場合は、不安解消向けの関連ページを先に確認するほうが整理しやすくなります。このページでは、まず全体像をつかむことを優先します。`

### Q3

- `セール情報はどの段階で確認すればよいですか？`

Draft answer:

`セール情報が気になる場合でも、まずは利用前の確認ポイントを押さえてから、最新情報の確認ページへ進むほうが判断しやすくなります。変わりやすい内容は別ページで公式案内を確認してください。`

FAQ rules:

- keep answers short
- no strong sale push
- no deep safety deep-dive
- no benefits-heavy explanation

- `1106 / 994 / 954` page rewrites

- SSH actions
