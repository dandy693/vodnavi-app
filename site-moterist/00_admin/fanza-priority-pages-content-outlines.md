# FANZA Priority Pages Content Outlines

## Scope

- Target pages: `1095 / 1106 / 994 / 954`
- Phase: structure design only
- This file defines page-specific content outlines, not rewrite copy
- No production WordPress changes are allowed from this document

## Shared Rules

1. Keep one dominant page role per page.
2. Keep FANZA official CTA stronger than internal-link guidance.
3. Keep `1018` `Pending Source Material` out of routine routing.
4. `954` defaults to `generic_latest_check_state`.
5. `954` uses `active_campaign_state` only when a current campaign is officially confirmed.

- intro section:
  - lower beginner anxiety
  - explain the page promise
- orientation section:
  - show the user what to check first
- confusion-reduction section:
  - reduce uncertainty about where to go next
- official confirmation section:
  - hand off to official latest-info confirmation
- next-step section:
  - move the user toward `1106` or `994`

### Elements To Keep

- beginner-entry framing
- role as top-of-funnel introduction
- links to `1106`, `994`, `954`

### Elements To Reduce Or Remove

- over-detailed feature lists too early
- benefits-heavy persuasion that belongs in `1106`
- crowded tail links

### New Elements To Add

- clearer first-step orientation box
- explicit beginner confusion-reduction section
- cleaner next-step hierarchy

### CTA Placement

### Section Purpose

- evergreen intro:
  - frame the page as a reusable sale hub, not a seasonal post
- comparison section:
  - teach users how to check offers safely
- current-campaign module section:
  - isolate all time-sensitive campaign facts
- related guidance section:
  - send users to `1106`, `994`, `1095` only as support
- final official CTA section:
  - make current sale confirmation the last action

### Elements To Keep

- sale-intent role
- clean sale-focused URL value
- internal support links to `1095`, `1106`, `994`

### Elements To Reduce Or Remove

- season-bound campaign framing
- old campaign names
- expired periods or discount figures in evergreen body
- actress-heavy clutter inside sale content

### New Elements To Add

- evergreen intro that works year-round
- explicit comparison guidance section
- replaceable current-campaign module
- generic latest-check default state
