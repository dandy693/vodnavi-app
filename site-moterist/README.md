# moterist-ai-affiliate

## 目的
moterist.comを、FANZA等の成人向けASPへ送客する比較・ランキング型メディアとして改善する。

## 基本方針
- 既存記事はすぐ削除しない
- 記事は keep / rewrite / noindex / merge / delete に分類する
- Xは直接販売ではなく、サイトへの集客口として使う
- 成果はPVではなく、FANZA送客率・成果発生・EPCで判断する
- 未成年を想起させる表現、無断素材、過度に露骨な表現は避ける

## AIチーム構成
- ChatGPT：戦略設計・分析・実装指示・コンプライアンス確認
- Claude：記事リライト・自然な文章作成・X投稿文作成
- Gemini：リサーチ・競合調査・ランキング調査
