## 3. URL / パーマリンク構造

| 種別 | パーマリンク例 | 備考 |
|---|---|---|
| 記事（コアピラー） | `https://moterist.com/<slug>/` | スラッグは英数字 + 日付形式（既存資産との互換維持のため、現時点で slug 変更や 301 は **しない**） |

| canonical | デフォルト維持 | 意図しない変更を入れないこと |

### 5.1 デザイン原則
1. **1 ページに「次の一歩」は 1 つだけ** 提示する。
2. **意図段階を分離**：理解 / 比較メリット / 不安解消 / セール確認 / アクトレスで絞る、を別ページに割り当てる。
3. 現行ライブ URL は **設計上のアンカーとして保持**。slug／301 はこのフェーズでは決めない。
4. ファクトが変動しがちな場面では **「確認」志向の CTA 文言** を使う（例：「公式で利用前の案内を確認する」）。
5. **954 は収益化ハブ**、**1018 はアクトレス・アーキテクチャ確定までは pillar 扱いしない**。

### 5.2 ピラー個別仕様
- **1095（Beginner Guide）**：ビギナー向け情報ブロック／導線分岐（メリット・安全・セール）を視認しやすく／末尾は視覚ノイズ低めに。リライトは中程度。
- **1106（Registration / Benefits Guide）**：benefit カードはコンプラ安全表現／高明度の単一 CTA ゾーン／ドリフトしやすいクレームは FAQ で簡潔に。リライトは中程度。
- **994（Safety / Anxiety Resolution）**：安心レイアウト／FAQ・チェックリスト・モジュール／事実と例示の区別を強める。リライトは中〜強（将来 FAQ クラスタ拡張前提）。
- **954（Evergreen Sale Hub）**：モジュラ更新エリア／エバーグリーン・リード・コピー／日付付き更新ブロック（本文丸ごと書き直さずに差し替えできる構造）。リライトはフル。季節依存をやめ通年運用。古いセール情報は本文に残さない運用。
- **1018（Pending Source Material）**：スタンドアロン時は支援フレーミング強化＋メタデータの安全化／統合時は salvageable な要約のみ転用し thin-post を解消。
