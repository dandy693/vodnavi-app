# Moterist AI Affiliate Agent Team

## 目的
moterist.comを、FANZA等の成人向けASPへ送客する比較・ランキング型メディアとして改善する。

## 最優先方針
1. 規約違反を避ける
2. 未成年を想起させる表現を避ける
3. 無断素材を使わない
4. 直接的・過激な表現を抑える
5. 読者が選びやすい比較・ランキング・レビュー型にする
6. 記事削除より、リライト・統合・noindexを優先する
7. 成果はPVではなく、FANZA送客率・EPC・成果発生で判断する
8. AIの出力は下書きとし、公開前に人間が確認する

## 禁止事項
- 未成年を想起させる表現
- 無断転載動画・画像の利用
- 他者投稿の流用
- スパム的なX運用
- 複数アカウントによる人工的な拡散
- 誇大表現
- 成果保証表現
- 過度に露骨な表現
- リンク先を隠すような誘導

## 役割分担
- ChatGPT：戦略設計、改善優先順位、分析、実装指示、コンプライアンス確認
- Claude：記事リライト、自然な日本語、X投稿文作成
- Gemini：リサーチ、競合調査、ランキング調査、表形式整理

## 最終判断
AIの出力は下書きであり、公開・削除・noindex・リダイレクトなどの最終判断は人間が行う。
