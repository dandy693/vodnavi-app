# Day 7 Core Articles Internal Link Plan

## Purpose

- 1095 / 1106 / 994 を競合記事ではなく、入口・比較検討・不安解消の3役でつなぐ
- 読者が現在地に応じて次に読むべき記事へ自然に移動できる導線を作る
- CTA と内部リンクの役割を分け、押し売り感を抑えながら回遊を増やす
- 将来の 954 セールハブ接続を前提に、3記事の基礎導線を先に整理する

## Article Roles

- 1095の役割
  - FANZAの基本、使い方の全体像、最初にどこを確認すべきかを案内する初心者向け入口記事
- 1106の役割
  - 登録や利用開始を迷う読者向けに、登録前後で確認したいメリットや判断ポイントを整理する比較検討記事
- 994の役割
  - 支払い、プライバシー、退会、問い合わせなどの不安を整理し、利用前に確認すべき点を案内する不安解消記事

## Recommended Link Flow

### From 1095

- 1106へ送る文脈
  - FANZAの基本を理解したあとに、登録すると何が確認しやすくなるかを知りたい読者を送る
- 994へ送る文脈
  - 支払い、退会、プライバシーなど、安全面の不安を先に解消したい読者を送る
- 954セールハブへ将来送る文脈
  - 基本を理解したうえで、開催中のセールやキャンペーンを確認したい読者を送る

### From 1106

- 1095へ戻す文脈
  - そもそもFANZAの基本や使い方から整理したい読者を入口記事へ戻す
- 994へ送る文脈
  - 登録前に支払い、プライバシー、退会まわりの不安を確認したい読者を送る
- 954セールハブへ将来送る文脈
  - 登録メリットを確認したあとに、お得情報や開催中の特典を見たい読者を送る

### From 994

- 1095へ戻す文脈
  - 安全面の前に、まずFANZAの全体像や基本的な使い方から把握したい読者を戻す
- 1106へ送る文脈
  - 不安を整理したうえで、登録メリットや利用開始前の判断材料を見たい読者を送る
- 954セールハブへ将来送る文脈
  - 安全面を確認したうえで、最新のセールやキャンペーンを見たい読者を送る

## Risk Notes

- 過度な性的表現を避ける
- 料金、キャンペーン、支払い方法、会員特典は固定情報として断定しない
- `絶対安全` `完全にバレない` などの保証表現を避ける
- PR/広告表記の文脈を壊さず、内部リンクは補足導線として置く
- CTA と内部リンクが同じ訴求を繰り返しすぎないようにする
